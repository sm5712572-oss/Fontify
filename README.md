# ✦ Fontify ✦

### Stylish Text & Symbols Generator ✨

Fontify is a simple and creative web tool that turns ordinary text into stylish, aesthetic and unique text.

🌐 **Live Website:**  
https://this-is-meee.github.io/Fontify/

## ✨ Features

- 🔤 Multiple stylish text styles
- 💖 Cute and aesthetic styles
- ✨ Symbols collection
- 📋 One-click copy
- ⭐ Rating system
- 📱 Mobile responsive design
- 💻 Works on desktop and mobile

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Supabase
